A stunning, modern, premium, and fully responsive 4-page continental restaurant web application designed for **PRETODAN RESTAURANT**. Built with a bold, vibrant, elegant aesthetic inspired by the restaurant's signature branding and menu flyer.

---

## 🎨 Brand Identity & Color Palette

- **Charcoal Black** (`#171513`): Dramatic dark slate backgrounds and surfaces
- **Golden Yellow** (`#F5A900`): Highlights, buttons, badge borders, and glowing accents
- **Burnt Orange** (`#E87516`): Primary call-to-actions, hover effects, and gradient transitions
- **Warm Cream** (`#F5E9D2`): Readable editorial typography and dividers
- **Pure White** (`#FFFFFF`): High-contrast headings and icons

---

## 🍽️ Pages Overview

### 1. Home Page
- **Cinematic Hero Slider (Slider Revolution Style)**: Multi-layered animated slider with Ken Burns zoom, staggered entrance animations, live progress indicators, pause/play toggle, and fluid dripping sauce vector header.
  - *Slide 1*: "A Taste of Excellence in Every Bite."
  - *Slide 2*: "Where Great Food Meets Great Moments."
  - *Slide 3*: "Fresh Ingredients. Exceptional Flavours."
- **Welcome Section**: Editorial copy introducing Pretodan's culinary philosophy and chef mastery.
- **Featured Dishes**: High-resolution catalog with filterable tabs across 6 categories:
  - Grilled Chicken
  - Beef Dishes
  - Pasta
  - Seafood
  - Rice Dishes
  - Continental Specialties
- **Why Choose Us**: 5 core value pillars with custom icons.
- **Services Preview**: Interactive cards highlighting key restaurant services.
- **Testimonials**: Verified customer reviews with 5-star ratings.
- **Final Call to Action**: "Good Food. Great Moments. Only at Pretodan."

### 2. About Us Page
- Story of Pretodan's culinary heritage and passion.
- Our Mission, Vision, and Core Values.
- Commitment to Quality (scratch cooking, sustainable sourcing, executive kitchen hygiene).
- High-resolution culinary ambiance gallery and action CTAs.

### 3. Our Services Page
- Displays all **7 Core Services**:
  1. *Dine-in Experience*
  2. *Takeaway Services*
  3. *Food Delivery*
  4. *Outdoor Catering*
  5. *Event Catering*
  6. *Online Food Ordering*
  7. *Private Dining*
- Dedicated ordering section with **Order Now** and **Order via WhatsApp** options.
- Complete interactive menu with real-time keyword search and category filtering.

### 4. Contact Us Page
- Editable contact placeholders: Phone, WhatsApp, Email, and Restaurant Address.
- Interactive contact & reservation form with client-side validation and confirmation feedback.
- Google Maps dark-mode integration placeholder and social media links.

---

## 🛒 Interactive Features

- **Cart Drawer**: Real-time subtotal, quantity updates, dynamic free delivery threshold ($70+), delivery address, and preparation instructions.
- **WhatsApp Order Generator**: Formats complete cart items, quantities, prices, notes, and delivery address into a pre-filled WhatsApp message.
- **Food Detail Modal**: In-depth dish specs, calories, prep time, spice level, and customization options.
- **Payment Gateway Simulation**: Interactive card and bank transfer checkout modal with celebratory confetti.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/<YOUR-USERNAME>/pretodan-restaurant.git

# Navigate into the project directory
cd pretodan-restaurant

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Building for Production

```bash
# Create optimized production build
npm run build

# Preview production build locally
npm run preview
```
